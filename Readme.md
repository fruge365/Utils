## 本地运行

不需要安装依赖，任选一种方式起本地服务（部分电脑上直接双击 HTML 也可运行）：

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

然后访问 `http://localhost:8080/`。
